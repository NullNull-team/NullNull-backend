# 널널 (NULLNULL) — 백엔드

> 붐비는 곳을 피해 여유 있는 공간을 찾아주는 캠퍼스 혼잡도 서비스

## 서비스 개요

수업 시간 직전 엘리베이터 앞에 인원이 집중된다. 학생은 얼마나 붐비는지 미리 알 수 없고, 학교는 동선 혼잡에 대한 데이터를 가지고 있지 않다.

BLE 광고 패킷을 수신해 엘리베이터 앞 혼잡도를 측정하고, 혼잡 단계로 환산해 실시간으로 전달한다. 학생은 계단과 엘리베이터 중 빠른 쪽을 고를 수 있고, 누적 데이터는 캠퍼스 동선 개선의 근거가 된다.

- 학생 기기에 별도 설치나 조작 없이 측정한다
- 식별자를 저장하지 않고 개수만 집계한다
