## 🚪 서비스 소개

수업 시작 직전, 엘리베이터를 기다릴지 계단으로 올라갈지 고민한 적 있나요?

**널널**은 엘리베이터 앞 혼잡도를 확인하고, 예상 이동 시간을 비교해 강의실까지 가는 길을 찾을 수 있도록 돕는 캠퍼스 서비스입니다.

주변 블루투스 신호를 집계해 혼잡도를 추정하며, 개인을 식별하는 대신 **얼마나 붐비는지**에 집중합니다.

## ✨ 주요 기능

| 기능 | 내용 |
|---|---|
| **실시간 혼잡도** | 건물별 엘리베이터 혼잡도를 색상과 점 개수로 확인 |
| **이동 시간 비교** | 목적지 층까지 엘리베이터와 계단의 예상 소요 시간 비교 |
| **강의실 경로 찾기** | 현재 위치와 도착 강의실을 기준으로 경로 안내 |
| **층별 이동 안내** | 지도 경로선과 층별 입체도로 건물 사이·층 사이 이동 확인 |
| **나의 시간표** | 요일별 수업을 등록하고 다음 수업의 경로로 빠르게 이동 |
| **출발 알림** | 다음 수업에 맞춰 출발 안내 확인 |
| **즐겨찾기** | 자주 이용하는 건물을 홈 목록 위쪽에 표시 |

### 혼잡도는 이렇게 표현해요

| 단계 | 표시 | 의미 |
|---|---|---|
| 🟢 **널널** | ●○○○ | 다음 엘리베이터에 여유 있게 탈 수 있어요 |
| 🟡 **쏘쏘** | ●●○○ | 다음 엘리베이터에 탈 수 있지만 꽉 차요 |
| 🟠 **답답** | ●●●○ | 한 대를 보내고 타야 해요 |
| 🔴 **빡빡** | ●●●● | 두 대 이상 보내고 타야 해요 |

> 혼잡도와 이동 시간은 센서 기반 추정값으로, 실제 이용 상황과 차이가 있을 수 있습니다.

## 🏫 대상 건물

**김수환관 · 마리아관 · 다솔관**

각 건물의 엘리베이터 위치와 계단 구성을 반영해 혼잡도 확인 및 층 이동 안내를 제공합니다.

## 🧭 이용 흐름

**혼잡도 확인**

홈 → 건물 선택 → 도착 층 선택 → 엘리베이터·계단 시간 비교

**강의실 찾기**

현재 위치 확인 → 건물·강의실 선택 → 경로 확인 → 건물별 층 이동 확인

**시간표 활용**

내 시간표 → 수업 추가 → 수업 선택 → 현재 위치 확인 → 경로 찾기

## 🔒 개인정보 보호 원칙

- 학생 기기에 측정용 앱을 설치하거나 별도로 조작할 필요가 없습니다.
- 측정 장치는 기기 식별자를 저장하지 않고 개수만 집계합니다.
- GPS 좌표는 기기 안에서 현재 건물이나 가까운 출입구를 판단하는 데 사용합니다.
- 즐겨찾기와 시간표는 사용자 기기에 저장합니다.
